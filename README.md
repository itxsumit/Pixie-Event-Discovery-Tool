# 🎟️ Pixie Event Discovery Tool

A Java-based web scraping application designed to automate the extraction and structured storage of public events and venue listings.

---

## 🚀 Overview
Pixie Event Discovery Tool fetches live event data (such as Jaipur and Mumbai event listings) using web scraping techniques and exports clean, structured datasets into Excel (`.xlsx`) formats for analysis and event discovery.

---

## 🛠️ Tech Stack
* **Language:** Java
* **HTML Parsing & Scraping:** Jsoup
* **Excel Data Export:** Apache POI
* **IDE / Build:** VS Code / Eclipse

---

## ✨ Features
* **Automated Data Scraping:** Extracts event titles, dates, locations, and descriptions from target web sources.
* **Excel Export:** Generates structured `.xlsx` spreadsheets (`Events_jaipur.xlsx`, `Events_mumbai.xlsx`).
* **Modular OOP Architecture:** Clean separation of data models (`Event.java`), scraper logic (`EventScraper.java`), and driver execution (`Main.java`).
